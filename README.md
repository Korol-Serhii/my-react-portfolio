# 🚀 My React Portfolio

Колекція React-проєктів для портфоліо: від месенджера до прикладних калькуляторів для щоденних задач.
Репозиторій використовується як навчальний полігон для сучасного фронтенд-стеку та вдосконалення архітектури.

## 📦 Проєкти (коротко)

| Проєкт | Опис | Основний стек |
| --- | --- | --- |
| `LinkUp` | Месенджер із багатомовністю та темами | React, TypeScript, Vite, Tailwind |
| `PlantApp` | Інтерфейс магазину рослин | React, Vite, Tailwind |
| `Vacation_calculator` | Калькулятор відпусток | React, Vite, Tailwind |
| `Years_of_service` | Калькулятор вислуги років з CSV-експортом | React, TypeScript, Vite, Tailwind |

## 🧩 Деталі по застосунках

### 💬 LinkUp
Месенджер із багатомовністю (uk/en), темами оформлення та модульною архітектурою.

- Авторизація та базова логіка користувачів
- Сторінки/роутинг через окремі модулі
- Підготовлена структура під масштабування (`app`, `pages`, `features`, `shared`, `i18n`)
- TypeScript + Vite + Tailwind CSS

### 🌱 PlantApp
Інтерфейс магазину рослин із каталогом, фільтрами та кошиком.

- Каталог товарів і базовий флоу покупок
- Адаптивний UI для мобільних і десктопних екранів
- React + Vite + Tailwind CSS

### 🏖️ Vacation_calculator
Калькулятор невикористаної відпустки для різних типів періодів.

- Розрахунок щорічної відпустки та УБД
- Підсумки по роках і загальний баланс
- React + Vite + Tailwind CSS

### 🎖️ Years_of_service
Калькулятор календарної та пільгової вислуги років.

- Розрахунки за коефіцієнтами (0.5 / 1 / 1.5 / 2 / 3)
- Таблична робота з періодами служби
- Експорт результатів у CSV
- TypeScript + Vite + Tailwind CSS

## 🛠️ Технологічний стек

- React 18
- TypeScript (поступова міграція в проєктах)
- Vite
- Tailwind CSS
- Lucide React
- i18next + react-i18next (у проєктах з багатомовністю)

## 🚀 Швидкий старт

### Вимоги

- Node.js 18+
- npm 9+

### Клонування репозиторію

```bash
git clone https://github.com/Korol-Serhii/my-react-portfolio.git
cd my-react-portfolio
```

### Встановлення та запуск

1. Перейдіть у потрібний проєкт:

```bash
cd LinkUp
# або
cd PlantApp
# або
cd Vacation_calculator
# або
cd Years_of_service
```

2. Встановіть залежності:

```bash
npm install
```

3. Запустіть dev-сервер:

```bash
npm run dev
```

4. Відкрийте адресу з консолі (зазвичай `http://localhost:5173`).

### Збірка та preview

```bash
npm run build
npm run preview
```

## 🧱 Структурний стандарт для нових/оновлених React-проєктів

Для TypeScript-проєктів використовується така структура:

```text
src/
├── app/
├── pages/
├── components/
├── features/
├── shared/
├── assets/
├── i18n/
├── router/
├── styles/
└── lib/
```

## 📌 Примітки

- Кожен застосунок у репозиторії є незалежним проєктом.
- Залежності встановлюються окремо в кожній директорії.
- Частина застосунків перебуває у процесі оновлення архітектури та міграції на TypeScript.
- Базова мова в i18n-проєктах: українська (`uk`) з підтримкою англійської (`en`).
